# 사칙연산이 가능한 계산기 프로그램 개발

이 프로그램은 파이썬 기본 라이브러리를 이용해서 사칙연산이 가능한 계산기 프로그램을 만들어라.

## 개발 목표
- 사칙연산이 가능한 계산기 프로그램 개발

## 구현 방법
- 파이썬 기본 라이브러리를 이용해서 사칙연산이 가능한 계산기 프로그램을 만들어라.

## 사용 예시
- 2 + 3 = 5
- 5 - 2 = 3
- 3 * 2 = 6
- 6 / 2 = 3
